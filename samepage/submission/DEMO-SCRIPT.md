# Silent demo, about 90 seconds

No voice. Every screen says what is happening; consensus waits are cut short with the transaction link left on screen.

| time | screen | what the viewer sees |
| --- | --- | --- |
| 0:00 | Landing | "Agree on the deal before the work starts." and the agreed deal card, term by term, read live from the chain |
| 0:08 | Open a page | Title, the counterparty's address, 20 GEN deposit; the link sent |
| 0:18 | Two wallets write and seal | Two different accounts; the side panel shows only the other side's seal hash |
| 0:32 | Open and check | "Validators are comparing", then DIFFERENT · 2, the differing terms hatched, both texts side by side |
| 0:50 | Round 2 | Both rewrite with the differing terms shown as a reminder; SAME PAGE |
| 1:05 | Sign | Both sign, the deposits back in the balances, the agreed record page; withdraw |
| 1:20 | Docs | The evaluation page with the golden cases and their transactions, the miss included |

The screenshots in `chain/out/screens/` are frames from the real browser run on the live contract and can be used as the storyboard.
