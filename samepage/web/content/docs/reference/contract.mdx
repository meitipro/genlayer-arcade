## no_show

```python
@gl.public.write
def no_show(self, page_id: int) -> None
```

Open to any caller on purpose: the rule decides who was absent from what is on chain, so the caller cannot change the outcome, and the side that was left waiting should not have to be the one online to settle it. After a missed window the absent side's deposit goes to the other side. A counterparty who never joined paid nothing, so the opener gets their own deposit back. When both sides missed the same step, nobody was left waiting, so each gets their own deposit back and both are recorded. A check that never landed inside its window is nobody's absence: the page closes NOT AGREED and both deposits come back, so a judgment that never finishes cannot hold anyone's money.

Refuses with: `no such page`, `this page is closed`, `the window for this step is still open`.

[Source, line 619](https://github.com/meitipro/genlayer-arcade/blob/claude/project-deploy-test-t7j87s/samepage/contracts/samepage.py#L619)
