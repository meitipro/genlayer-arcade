A seal is the lower-case hex sha256 of the UTF-8 bytes of `text|salt|address`:

<Tabs items={['Contract (Python)', 'Browser (TypeScript)', 'Scripts (Python)']}>
<Tab value="Contract (Python)">

```python title="contracts/samepage.py"
def seal_of(text: str, salt: str, address_hex: str) -> str:
    """
    sha256 over the UTF-8 bytes of "text|salt|address", the address lower case
    with its 0x. The browser computes the same bytes; tests/vectors.json holds
    the shared vectors.

    The address is inside the hash, so a seal copied from the other side can
    never be opened by the side that copied it. The salt is hex only, so it can
    never contain the separator, and the split of a preimage into text and salt
    is unique: a writer cannot seal "A|B" and later choose whether their
    account was "A" or "A|B".
    """
    return hashlib.sha256((text + "|" + salt + "|" + address_hex.lower()).encode("utf-8")).hexdigest()
```

</Tab>
<Tab value="Browser (TypeScript)">

```ts title="web/lib/chain.ts"
/** sha256 over the UTF-8 bytes of "text|salt|address", the address lower case. Same bytes as the contract. */
export async function sealOf(text: string, salt: string, address: string): Promise<string> {
  const bytes = new TextEncoder().encode(`${text}|${salt}|${address.toLowerCase()}`);
  const digest = await crypto.subtle.digest("SHA-256", bytes);
  return Array.from(new Uint8Array(digest), (b) => b.toString(16).padStart(2, "0")).join("");
}
```

</Tab>
<Tab value="Scripts (Python)">

```python title="scripts/chain.py"
def seal_of(text: str, salt: str, address: str) -> str:
    import hashlib

    return hashlib.sha256((text + "|" + salt + "|" + address.lower()).encode("utf-8")).hexdigest()
```

</Tab>
</Tabs>

- The address is lower-cased on both sides, with its `0x`.
- The salt must be 16 to 64 lower-case hex characters; `reveal` refuses anything else, so the preimage splits into text and salt in exactly one way.
- Text is hashed exactly as written. Nothing is trimmed or normalised, so a trailing space or a different apostrophe is a different seal.
- `seal` accepts the hash with or without `0x` and in either case, and stores it lower case without `0x`.

## Test vectors

`tests/vectors.json` is shared: `tests/test_direct.py` checks every vector against the contract's `seal_of`, and `web/scripts/vectors.test.mjs` checks them against the browser's `sealOf`.

The rule, as `tests/vectors.json` states it: sha256 over the UTF-8 bytes of text + '|' + salt + '|' + lower-case address with 0x; salt is 16 to 64 lower-case hex characters.
